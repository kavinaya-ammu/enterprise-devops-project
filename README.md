# Enterprise DevOps Project

End-to-end DevSecOps platform using:

- Git
- GitHub
- Java
- Maven
- Jenkins
- SonarQube
- Trivy
- Nexus
- Docker
- Kubernetes
- Argo CD
- WebLogic
- Oracle Database
- Prometheus
- Grafana

## Maven CI Build

The project uses Maven for build and validation.

### Build Commands

mvn clean
mvn validate
mvn compile
mvn test
mvn package
